# Shanghai GDP forecasting with rolling validation

This R project reproduces and improves the forecasting workflow from a time-series course paper. It asks: **how accurately can models forecast Shanghai nominal GDP when they are evaluated on years they have not seen?**

The dataset contains 50 annual observations from 1969 to 2018. Three approaches are compared:

- random walk with drift;
- Holt exponential smoothing;
- ARIMA selected from a small candidate grid using AICc.

The main improvement over the original paper is expanding-window, one-step-ahead validation. Model selection is based on forecasts of unseen years rather than in-sample fit alone.

## Results

| Model | Rolling forecasts | MAE | RMSE | MASE | 95% interval coverage |
|---|---:|---:|---:|---:|---:|
| ARIMA | 25 | 381.53 | 525.86 | 0.298 | 100% |
| ETS | 25 | 386.48 | 532.64 | 0.302 | 100% |
| Drift | 25 | 450.30 | 638.20 | 0.352 | 96% |

ARIMA has the lowest rolling RMSE. Refitting the selected low-order candidate grid to the complete sample gives **ARIMA(1,2,2)**. Its residual Ljung-Box test has `p = 0.3083`, which does not provide sufficient evidence of remaining autocorrelation.

## Workflow

```text
Raw CSV
  -> validation and feature generation
  -> exploratory analysis
  -> Drift, ETS and ARIMA models
  -> expanding-window validation
  -> residual diagnostics
  -> final forecast and generated report
```

## Run the project

The first version uses only packages included with base R.

From the project directory, run:

```powershell
& 'C:\Program Files\R\R-4.6.1\bin\Rscript.exe' run_project.R
```

The script validates the data, rebuilds every derived file, and prints the selected model. The complete generated analysis is in [analysis/report.md](analysis/report.md).

## Reproducibility

Delete `data/processed`, `outputs`, and `analysis/report.md`, then rerun `run_project.R`. All derived artifacts will be rebuilt from the raw CSV.

## Methodological choices

- Models are trained only on information available before each forecast year.
- The first 25 observations form the initial training window.
- ARIMA candidates are restricted to `p, q <= 2` and selected using AICc within each training window.
- Final model choice uses rolling RMSE rather than in-sample fit.
- Predictions are produced on the log scale and transformed back to nominal GDP.

## Limitations

- The data represent nominal GDP, combining real growth and price changes.
- The annual sample is small and cannot describe short-run economic dynamics.
- No external economic variables or structural-break indicators are included.
- Back-transformed point forecasts are medians; no log-normal bias correction is applied.
- Results are a reproducible modeling exercise rather than economic policy guidance.
